Anda boleh import data pelajar sedia ada ke dalam MUDEER dengan memuat naik file Excel dalam format yang ditetapkan.

Contoh format Excel boleh dimuat turun melalui menu **Students → Import → Upload**.

![](Import%20Data%20Pelajar/image2.png)

Klik **Template** untuk memuat turun salinan template tersebut.

![](Import%20Data%20Pelajar/image1.png)

Berikut adalah medan yang ada dalam template tersebut:

1. **name** (wajib) - Nama pelajar.
2. **sponsor** - Nama ibu bapa. Boleh dibiarkan kosong. Nama ini akan terpapar pada setiap invois.
3. **phone** (wajib) - Nombor telefon untuk penghantaran notifikasi.
4. **email** - Alamat emel untuk penghantaran notifikasi. Tidak wajib.
5. **address** - Alamat rumah atau surat menyurat. Tidak wajib.
6. **ic_number** - No. Kad Pengenalan pelajar atau ibu bapa. Nilai phone akan diambil sekiranya nilai ini dikosongkan.
7. **fee_rate** - Kadar yuran bulanan. Jika maklumat ini dibiarkan kosong, yuran pelajar akan mengikut yuran course.
8. **prorate** - Yuran mengikut sesi atau jam bagi course yang ditetapkan sebagai prorate. Boleh dibiarkan kosong.
9. **outstanding** - Baki hutang pelajar. Boleh dibiarkan kosong.
10. **teacher_name** - Untuk pelajar kelas individu sahaja. Nama tutor yang mengajar.
11. **teacher_phone** - No. Telefon tutor yang mengajar.
12. **teacher_ic_number** - No. Kad Pengenalan tutor. Akan digunakan sebagai katalaluan untuk tutor log masuk.
13. **teacher_email** - Alamat emel tutor. Untuk log masuk dan penghantaran notifikasi.

Bila file Excel siap diisi, boleh muat naik di paparan **Import Students.** Tekan **Browse** dan pilih file Excel tersebut.

![image.png](Import%20Data%20Pelajar/image.png)

Tandakan kelas pelajar. Jika kelas belum ditentukan, tandakan **Not in any class**.

![image.png](Import%20Data%20Pelajar/image%201.png)

Jika **Charge Course Fees** ditandakan, invois pertama akan dijana untuk setiap pelajar dalam senarai tersebut.

![image.png](Import%20Data%20Pelajar/image%202.png)

Klik **Continue**.

Anda akan nampak senarai pelajar yang terkandung dalam file Excel yang dimuat naik. Tekan **Import** untuk mendaftarkan semua pelajar.

![image.png](Import%20Data%20Pelajar/image%203.png)

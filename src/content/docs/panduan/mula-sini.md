# Selamat Datang!

Terima kasih kerana memilih MUDEER untuk bantu anda kutip yuran, uruskan kelas dan bayar elaun tutor dengan lebih handal.

Untuk mula menggunakan MUDEER, anda tak perlu buat semua sekali gus. Berikut adalah 3 langkah utama yang anda perlu buat:

1. Wujudkan kursus dan buka kelas.
2. Daftarkan pelajar.
3. Tetapkan tutor.
